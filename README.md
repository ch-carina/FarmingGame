# Sprouts

小さな農場を切り盛りしながら、作物を狙う動物たちから畑を守る、見下ろし視点の「農場経営 × 防衛アクション」ゲームです。DirectX 11 を用いて C++ でスクラッチ開発されています。

## ゲーム概要

プレイヤーは自分の農場を持つ新米農家。畑に種をまき、水をやり、育った作物を収穫して売り、決められた時間内に目標金額を稼ぐことを目指します。

ただし畑を放っておくとウサギやモグラが作物を食い荒らしにやってきます。銃で撃退したり、フェンスやかかしで畑を守ったりしながら、農作業と防衛を同時にこなす忙しさがこのゲームの核となっています。

- **農場を育てる**: 種まき → 水やり → 収穫 → 販売のサイクルでお金を稼ぐ
- **農場を守る**: ウサギ・モグラなどの動物を銃・フェンス・かかしで撃退する
- **農場を発展させる**: レベルクリアで得られる恒久アップグレードでプレイスタイルを強化する

## 遊び方

### 操作方法

| キー | 動作 |
|---|---|
| W / A / S / D | 移動(向いている方向も決まる) |
| 矢印キー(↑↓←→) | 射撃時の照準方向/メニューでの選択移動 |
| SPACE(長押し) | 銃で弾を発射 |
| E(長押し・決定) | 種まき・水やり・収穫・フェンス設置・かかし設置・購入・売却など、あらゆる操作の基本キー |
| 1〜6 | インベントリのスロット選択(全6スロット) |
| ENTER | メニューの決定 |
| ESC | ショップや説明パネルを閉じる |

### 敵となる動物たち

- **ウサギ**: 画面端から出現し、狙った畑に向かって突進してくる。畑に到着すると2秒後に作物を食べて逃げていく。銃で撃つと怯んで逃げていくが、一撃では倒せない。フェンスにぶつかると強制的に逃走する。
- **モグラ**: 狙った畑の位置に土の中からせり出して出現(約1.5秒)。放置すると2秒後に作物を食べて地中に潜って逃げる。体当たりされると作物は即座に壊されてしまうが、銃で撃てば一撃で倒せる。
- **フェンス**: 畑の周囲に設置できる防具。動物からの攻撃を3回受けると壊れる。設置されている間は動物だけでなくプレイヤー自身の移動も塞ぐ壁として機能する。
- **かかし**: ショップで購入できるアイテム。設置すると10秒間、近づいてきた動物を追い払ってくれる。
- 動物に直接触れるとノックバックと画面フラッシュのダメージ演出を受ける(接触後1秒間は無敵)。

## 魅力ポイント

- **農業シム×防衛アクションの掛け合わせ**: のんびり作物を育てるだけでなく、動物から畑を守るスリルが加わり、常に忙しく飽きの来ないゲームプレイになっています。
- **敵ごとに異なる対策が必要な戦略性**: 突進してくるウサギと、狙った場所に出現するモグラでは有効な対処法が異なり、銃・フェンス・かかしをどう使い分けるかがプレイヤーの腕の見せどころです。
- **時間制限と目標金額によるテンポの良さ**: 各レベルにタイムリミットと金額目標があるため、限られた時間の中で植える・育てる・守る・売るをどう回すか考える判断力が試されます。
- **水やりによる一手間の価値**: ただ収穫するだけでなく水やりを挟むことで作物のランクが上がり、収益効率にひと工夫加えられます。
- **段階的な成長システム**: レベルクリアごとに得られるアップグレードでプレイスタイルが少しずつ強化されていき、周回するたびに立ち回りが変わります。
- **丁寧なチュートリアル**: 初めてのプレイヤーでも迷わず遊べるよう、操作の説明が段階的に用意されています。
- **シェーダー開発への挑戦**: グラフィック表現を向上させるため、自作シェーダーの開発にも取り組みました。本作ではぼかし表現のBlur Shader、スポットライト演出のSpotlight Shader、水面表現のWater Shaderを実装しています。DirectXのシェーダープログラミングを学習しながら制作を進めることで、ゲームの世界観や雰囲気をより豊かに表現できるようになりました。
- **描画順を管理するDraw Queueの実装**: プレイヤーが物陰の前後どちらにいるかを正しく表現するため、描画リクエストをY座標でソートしてから描画するDraw Queueシステムを自作しました。これにより奥行きのある見下ろし視点の演出を実現しています。
- **ASCIIテクスチャアトラス方式の自作フォントシステム**: 文字を表示するたびにスプライトシートを個別に用意する必要がないよう、ASCII文字をまとめた1枚のテクスチャアトラスから文字を描画する自作フォントシステムを実装しました。ドロップシャドウ付きのテキスト描画や、表示サイズの計測にも対応しています。
- **リーダーボードによる達成の記録**: 到達したレベルとその時点の所持金がプレイのたびに記録され、上位5件がリーダーボードに保存されます。自分がどこまで到達できたかが形に残ることで、もう一度挑戦してみたいという気持ちにつながります。
